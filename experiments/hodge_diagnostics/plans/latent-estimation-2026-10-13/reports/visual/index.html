One skew matrix Ā; every prompt sees a compression of it

Each prompt’s cycle depends only on Ācyc, and only Ācyc survives a shift of the attribute origin: it is the object to find.

Prop L1: Ca = Φ̃a Ācyc Φ̃aᵀ. Shares from the framework note’s synthetic check §5(2): random standard-normal attributes in 3-D, pure latent cycle, 200 panels per size (6 responses: 67%). Illustrative matrix entries.

Estimate Ā from pooled sparse pairs, with one regression

So features must vary continuously across prompts on the same attribute: embedding PCA first, judge-scored attributes second.

Prop L2 as corrected by the referee; numbers from the framework note §5(1). S1 features: embedding PCA to d ∈ {8, 16}; one judge call per response, 0–10 on about 6–8 style attributes plus length; the cheap length set for comparison with 09-25. All centred on the pooled mean.

The shared cycle is a rotation plane, and it must beat three nulls

Shuffle and flip destroy only alignment; the surrogate is the transitive baseline. Beating all three means a shared direction.

Thm L3; handoff S3 (corrected 10-13). Primary policy: the initial checkpoint’s πa (uniform secondary); all nulls and ω̃₁ on the held-out half. Synthetic check (framework §5(3)): ω̃ = 0.0797 ⇒ β* = 5.47 at α = 0.9, λ = 1. Right panel schematic.

Background: the one-hot version found alignment real but small

Every shared ω̃ beat its shuffle null, but stayed at 10–41% of the per-prompt scale and below a transitive surrogate: mostly an artefact of discrete labels.

Prior diagnostic, not a result of this plan. One-hot shared features only (model identity, or length rank); exact shared dynamics did not cycle. S1–S3 extend this tool to continuous features, where coherence was not excluded.
